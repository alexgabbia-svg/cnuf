Painel da Copa CNUF

Cole as súmulas, agende os jogos e gere o arquivo copa-data.js. Depois é só substituí-lo no repositório do GitHub e o site se atualiza.

1. Adicionar súmula

Cole o texto da súmula no mesmo formato do WhatsApp. O placar é calculado pela soma dos gols.

2. Agendar jogo

3. Arquivo atualizado

Copie ou baixe e substitua copa-data.js no GitHub (Add file > Upload files, ou o lápis para editar).
